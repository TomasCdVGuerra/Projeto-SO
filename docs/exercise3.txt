Exercise 3 – Paralelização usando múltiplas tarefas (Implementation Documentation)

OVERVIEW
Exercise 3 adds threading so monsters can move independently without waiting for user input, while keeping ncurses single-threaded. This implementation uses FINE-GRAINED LOCKING (per-position mutexes) to maximize parallelism as requested by instructor feedback.

IMPLEMENTATION APPROACH: PER-POSITION LOCKING

Based on instructor feedback: "A ideia é o teu programa permitir que, por exemplo, a thread de uma personagem não bloqueie todas as outras threads de personagens se está a mexer em posições que nenhuma outra thread esteja a mexer. Isto implica a que cada posição do tabuleiro tenha o seu mecanismo de exclusão."

Step 1: Add threading infrastructure to board
  File: `include/board.h`
  
  What:
  - Add to board_pos_t:
    ```c
    typedef struct {
        char content;
        int has_dot;
        int has_portal;
        pthread_mutex_t pos_mutex;  // NEW: Per-position lock
    } board_pos_t;
    ```
  
  - Add to board_t:
    ```c
    simple_barrier_t turn_barrier;  // Custom barrier (macOS compatible)
    pthread_t *ghost_threads;       // Array of worker thread handles
    int threads_active;             // Flag: 1 = running, 0 = stop
    ```
  
  - Add custom barrier struct (macOS doesn't have pthread_barrier_t):
    ```c
    typedef struct {
        pthread_mutex_t mutex;
        pthread_cond_t cond;
        int count;
        int threshold;
        int generation;  // For reusability
    } simple_barrier_t;
    ```
  
  Why:
  - Per-position mutexes allow concurrent moves when positions don't overlap
  - Barrier synchronizes turn-based steps (all ghosts move, then main renders)
  - Custom barrier needed for macOS compatibility
  - Need handles to join threads on level end

Step 2: Initialize per-position mutexes

  What:

    board->board = calloc(board->width * board->height, sizeof(board_pos_t));
    
    for (int i = 0; i < board->width * board->height; i++) {
        pthread_mutex_init(&board->board[i].pos_mutex, NULL);

    3. `restore_from_backup()` - quicksave restoration
  
  Why:
  - Each position needs its own lock before threads start
  - Must initialize after allocation but before threads spawn
  - Covers all paths that create new boards

Step 3: Implement lock ordering helpers and barrier
  File: `src/board.c`
  
  What:
  - Lock ordering strategy to prevent deadlocks:
    ```c
    static void lock_two_positions(board_t *board, int idx1, int idx2) {
        if (idx1 == idx2) {
            pthread_mutex_lock(&board->board[idx1].pos_mutex);
        } else if (idx1 < idx2) {
            pthread_mutex_lock(&board->board[idx1].pos_mutex);
            pthread_mutex_lock(&board->board[idx2].pos_mutex);
        } else {
            pthread_mutex_lock(&board->board[idx2].pos_mutex);
            pthread_mutex_lock(&board->board[idx1].pos_mutex);
        }
    }
    
    static void unlock_two_positions(board_t *board, int idx1, int idx2) {
        pthread_mutex_unlock(&board->board[idx1].pos_mutex);
        if (idx1 != idx2) {
            pthread_mutex_unlock(&board->board[idx2].pos_mutex);
        }
    }
    ```
  
  - Custom barrier implementation (generation-based for reusability):
    ```c
    void barrier_wait(simple_barrier_t *barrier) {
        pthread_mutex_lock(&barrier->mutex);
        int my_generation = barrier->generation;
        barrier->count++;
        
        if (barrier->count >= barrier->threshold) {
            barrier->count = 0;
            barrier->generation++;
            pthread_cond_broadcast(&barrier->cond);
            pthread_mutex_unlock(&barrier->mutex);
        } else {
            while (my_generation == barrier->generation) {
                pthread_cond_wait(&barrier->cond, &barrier->mutex);
            }
            pthread_mutex_unlock(&barrier->mutex);
        }
    }
    ```
  
  Why:
  - Always lock lower index first prevents circular wait (deadlock)
  - Generation-based barrier can be reused multiple times per level
  - Handles same-position case (moving in place)

Step 4: Create worker thread function
  File: `src/game.c`
  
  What:
  ```c
  void* ghost_worker(void* arg) {
      ghost_thread_args_t *args = (ghost_thread_args_t*)arg;
      board_t *board = args->board;
      int ghost_idx = args->ghost_index;
      
      while (board->threads_active) {
          barrier_wait(&board->turn_barrier);
          
          if (!board->threads_active) {
              break;
          }
          
          ghost_t *ghost = &board->ghosts[ghost_idx];
          command_t *cmd = &ghost->moves[ghost->current_move % ghost->n_moves];
          move_ghost(board, ghost_idx, cmd);  // Locks internally
          
          barrier_wait(&board->turn_barrier);
      }
      
      free(args);
      return NULL;
  }
  ```
  
  Why:
  - Each worker loops: wait → move (with fine-grained locking) → wait → repeat
  - NO global lock here - locking happens inside move_ghost() per position
  - Barrier ensures discrete turns (all ghosts move, then main renders)
  - Check threads_active after first barrier to exit cleanly

Step 6: Initialize threads and barrier
  File: `src/game.c`
  
  What:
  - Create init_threads() helper:
    ```c
    static void init_threads(board_t *game_board) {
        barrier_init(&game_board->turn_barrier, game_board->n_ghosts + 1);
        game_board->threads_active = 1;
        
        game_board->ghost_threads = malloc(game_board->n_ghosts * sizeof(pthread_t));
        
        for (int i = 0; i < game_board->n_ghosts; i++) {
            ghost_thread_args_t *args = malloc(sizeof(ghost_thread_args_t));
            args->board = game_board;
            args->ghost_index = i;
            pthread_create(&game_board->ghost_threads[i], NULL, ghost_worker, args);
        }
    }
    ```
  
  - Call after level loads in main():
    ```c
    load_next_level(&game_board, accumulated_points);
    init_threads(&game_board);
    ```
  
  Why:
  - Barrier count = n_ghosts + 1 (main thread participates)
  - One thread per ghost
  - Pass index so worker knows which ghost to control
  - Allocate args per thread (freed in worker on exit)

Step 7: Modify main game loop (turn-based sync)
  File: `src/game.c` - play_board() function
  
  What:
  ```c
  int play_board(board_t *game_board) {
      // Get input (non-blocking)
      command_t c;
      c.command = get_input();
      if (c.command == '\0') return CONTINUE_PLAY;
      
      // Handle special commands (Q, G)
      if (c.command == 'Q') return QUIT_GAME;
      if (c.command == 'G') return CREATE_BACKUP;
      
      // Synchronize turn start - all threads wait here
      barrier_wait(&game_board->turn_barrier);
      
      // Move pacman (locks its positions internally)
      int result = move_pacman(game_board, 0, &c);
      
      // Render (only main thread touches ncurses)
      draw_board(game_board, DRAW_MENU);
      refresh_screen();
      
      // Synchronize turn end - wait for all workers
      barrier_wait(&game_board->turn_barrier);
      
      return result;
  }
  ```
  
  Why:
  - Barrier at start: workers wait for turn signal
  - Main moves pacman with fine-grained locking (NOT global lock)
  - Draw board (ncurses safe - only main thread)
  - Barrier at end: workers wait for render done
  - Creates discrete turns: input → all move (parallel) → render → repeat

Step 9: Stop and join threads on level end
  File: `src/game.c`
  
  What:
  - Create cleanup_threads() helper:
    ```c
    static void cleanup_threads(board_t *game_board) {
        game_board->threads_active = 0;
        
        // Wake threads from barrier (they'll see threads_active=0 and exit)
        barrier_wait(&game_board->turn_barrier);
        
        // Join all threads
        for (int i = 0; i < game_board->n_ghosts; i++) {
            pthread_join(game_board->ghost_threads[i], NULL);
        }
        
        free(game_board->ghost_threads);
        barrier_destroy(&game_board->turn_barrier);
    }
    ```
  
  - Call before unload_level() in main():
    ```c
    cleanup_threads(&game_board);
    print_board(&game_board);
    unload_level(&game_board);  // Destroys per-position mutexes
    ```
  
  Why:
  - threads_active=0 tells workers to exit loop
  - Barrier wake-up ensures threads see the flag
  - pthread_join() waits for clean exit (no zombies)
  - Destroy barrier before next level
  - unload_level() destroys all per-position mutexes

Step 10: Cleanup per-position mutexes
  File: `src/board.c` - unload_level()
  
  What:
  ```c
  void unload_level(board_t *board) {
      // Destroy all position mutexes before freeing
      for (int i = 0; i < board->width * board->height; i++) {
          pthread_mutex_destroy(&board->board[i].pos_mutex);
      }
      free(board->board);
      free(board->pacmans);
      free(board->ghosts);
  }
  ```
  
  Why:
  - Must destroy mutexes before freeing memory
  - Prevents resource leaks
  - Called after threads are joined (no contention)

Step 11: Handle quicksave in threaded mode
  File: `src/game.c`
  
  What:
  - **Save (Fork)**:
    - Before `fork()`: Call `cleanup_threads()` to stop all ghosts and release locks.
    - After `fork()` (in parent): Call `init_threads()` to restart them.
  - **Restore**:
    - Before restore: Call `cleanup_threads()`.
    - During restore: Re-initialize all `pos_mutex` fields in the board array.
    - After restore: Call `init_threads()`.
  
  Why:
  - **Thread Safety**: Forking with active threads is dangerous because mutex states are copied but owner threads are not. This leads to "ghost locks" in the child process.
  - **Solution**: Ensure the board is "quiescent" (no active threads, no held locks) before taking the snapshot.
  - **Recovery**: Even with precautions, we explicitly reset mutexes on restore to guarantee a clean slate.

WHY THIS APPROACH (FINE-GRAINED LOCKING)

Key Design Decision: Per-Position Locking vs Global Locking
- IMPLEMENTED: Each board position has its own mutex
- ALTERNATIVE (simpler but rejected): One global board_mutex
- REASON: Instructor feedback explicitly requested per-position exclusion
- BENEFIT: Multiple ghosts move simultaneously when accessing different positions

Technical decisions:
- One thread per ghost: Natural mapping, easy to reason about
- Main thread owns ncurses: ncurses is NOT thread-safe; violation causes corruption
- Per-position mutexes: Maximizes parallelism (instructor requirement)
- Lock ordering: Prevents deadlocks (always lock lower index first)
- Barrier for turns: Makes game deterministic (discrete ticks)
- Non-blocking input: Game doesn't pause waiting for user
- Custom barrier: macOS compatibility (no pthread_barrier_t on macOS)

Turn-based vs free-running:
- Turn-based (barrier): All entities move once per tick, predictable
- Free-running (no barrier): Entities move at own pace, complex to balance
- CHOSEN: Turn-based easier to debug and matches original design

Collision handling:
- Lock order determines winner when two ghosts want same cell
- First ghost to acquire lock and move wins
- Reuses existing move_ghost logic (checks walls/ghosts/pacman)

Deadlock Prevention:
- Always lock positions in index order (lower first)
- Helper functions enforce this ordering
- Same-position case handled specially (only one lock)

Memory safety:
- All board position access protected by position-specific lock
- No data races on board cells
- Entity state (pos_x, pos_y) updated atomically with board update
- Each thread has private stack (args, local vars)

Parallelism Analysis:
- WORST CASE: All ghosts want adjacent positions → serialized
- BEST CASE: Ghosts on opposite sides of board → fully parallel
- TYPICAL: Ghosts in different areas → high parallelism
- IMPROVEMENT over global lock: ~N-fold speedup for N independent moves

Assignment requirements met:
✓ Each character in separate thread
✓ Only main thread touches ncurses
✓ Maximizes parallelism (per-position exclusion as requested)
✓ Scalable sync (independent moves don't block each other)
✓ Works with Exercise 1 (multi-level) and Exercise 2 (quicksave)
✓ Instructor-compliant: "cada posição do tabuleiro tenha o seu mecanismo de exclusão"

macOS Compatibility:
- pthread_barrier_t not available on macOS
- Implemented generation-based barrier using mutex + condition variable
- Reusable across multiple turns (generation counter prevents race)
- Functionally equivalent to pthread_barrier_t
